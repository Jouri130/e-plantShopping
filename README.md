
# Paradise Nursery

Paradise Nursery is a React shopping application for an online plant shop.

## Features
- Browse houseplants in different categories.
- View plant images, names, descriptions, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove plants from the cart.
- Calculate item totals and the total cart amount.

## Technologies
- React
- JavaScript
- CSS
- Redux Toolkit

## Project Purpose
This project demonstrates front-end development, React components, state management, and shopping cart functionality.
